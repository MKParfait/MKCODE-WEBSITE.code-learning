Experiment, observe, repeat.

Use the editor to understand how the three core web technologies work together.

HTML

Describe the content

Use elements such as headings, paragraphs, links, images, and buttons to give a page its structure.

CSS

Style the page

Change colors, spacing, layout, borders, and typography to create a visual identity.

JS

Add interaction

Respond to events, update text, and make buttons or other page elements do something.

console.log("Hello!");

Good playground habits
